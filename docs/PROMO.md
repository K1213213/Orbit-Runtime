# ORBIT RUNTIME

> **可复现 · 可证明 · 可核算**
> 面向生产的 Agent 运行时内核——不是更强的编排框架，而是让每一次 Agent 行为都能被复现、被证明、被核算。
> 你的编排代码不用改——把工具调用交给它。

```bash
npm i orbit-runtime   # v0.12.0 · Apache-2.0 · 零运行时依赖
```

## Agent 上生产之后，三个没人能回答的问题

| 问题 | 现场 |
|---|---|
| **01 复现不了** | 它删错了生产库的一张表。重跑十次结果次次不同——模型采样、工具副作用、并发时序，没有任何一次能回到出错那一刻。日志只留下"发生过"，没有"怎么再来一次"。**根因：运行时的默认值是"不确定"。** |
| **02 证明不了** | 复盘会上你拿出日志，安全团队问："谁能证明这条日志没被改过？这个插件的故障影响范围是哪里？"日志是文本，文本可以编辑。**根因：审计是事后补的，不是运行时给的。** |
| **03 核算不了** | 月底账单 8 万。哪一次调用走了贵模型？哪一次被熔断重试了三遍？财务要的是单次可归因的账目。**根因：成本只有总数，没有明细。** |

## 先说它不是什么——边界就是定位

Agent 编排已有成熟方案（LangGraph / AutoGen / CrewAI），模型能力日新月异，工具生态由 MCP 打通。**Orbit 不参与这些竞赛**，它补的是下面那一层：当编排层调用工具时，让这一次调用**可复现、可证明、可核算**。

- ❌ 不做 Agent 编排框架——那是 LangGraph / Harness 的主场
- ❌ 不做模型训练与推理——模型是通道背后的服务
- ❌ 不自研工具生态——通道接文件、接 Shell、接 MCP / OpenAPI / Cordis

## 一、可复现：重放零外部调用，输出逐字节一致

**0 次真实外部调用**——重放时，每一次通道调用都由冻结快照接管：不碰模型、不碰磁盘、不碰网络，输出与录制时逐字节相同。

**~300ms → ~1ms** —— 控制台实测：真实运行 vs 确定性重放。

```ts
// 1. 录制一次真实运行
const journal = host.beginRecording();
await host.capabilityInvoke({ capability: "llm-access", input: "..." });
// 2. 重放：零模型调用，字节级一致
const replay = host.replay(journal);
```

**五分钟自己验证**（四条命令）：

```bash
# 1. 装包（零依赖，仅 devDependency 跑测试）
npm install orbit-runtime
# 2. 录制一次真实运行（任何 capability 都会被快照）
node examples/cli-record-replay/run.mjs record
# 3. 零调用重放，diff 必须为空
node examples/cli-record-replay/run.mjs replay
node examples/cli-record-replay/run.mjs diff
```

## 二、可证明：故障隔离是图论问题，审计轨迹是哈希链

**故障隔离 = 反向可达闭包**。"这个插件挂了会影响谁"不是靠经验猜，而是图上的反向可达闭包。两个闭包互不相交，则故障互不传染——**一条可静态验证的隔离定理**，注册期就做能力闭包检查。

**审计轨迹 = HMAC 哈希链**。每条审计带 `prevHash / chainHash`。改一条、删一条，都会从第 k 条起断裂并被定位——"删一条日志"这种事，在 Orbit 里会被当场发现。

## 三、可核算：每一次调用的决策，都在记录里

网关对每个调用做出四类决策并**全部留痕**。成本不再是月底的一个总数，而是可归因、可回放、可对比的单次账目。

| 决策 | 说明 |
|---|---|
| **路由决策** | 这次调用走原生通道还是外来适配器（PAE）？通道声明成本/延迟/质量画像，路由在预算内选最便宜的一条 |
| **预算决策** | `allow / shrink / stop` 三态：允许、收缩上下文、停止 |
| **限流/熔断** | 纯函数限流器 + 每插件故障状态机（NORMAL → TRIPPED → PROBE） |
| **压缩/审计** | 载荷感知压缩留痕、每笔调用写入审计链 |

## 一条刻度盘：同一套代码，从开发跑到合规

开发时零摩擦，上线时收紧——**四档治理切换只改一个配置项**。档位差异会进入运行指纹，跨档重放直接报配置漂移——不会出现"在我机器上是合规的"。

| 档位 | 行为 |
|---|---|
| dev | 全放开 |
| prod | 熔断/限流生效 |
| audit | 轨迹持久化 |
| **strict** | 强制签名 + 启动时验证整条链；**被篡改 → 拒绝启动**，不留"带病运行" |

## 审计三件套

1. **哈希链**（HMAC 逐条串联）——回答"这条轨迹有没有被动过"：`verifyAuditChain()` · `orbit audit`
2. **合规报告**——把治理档位、审计状态、治理干预统计收敛成报告，状态诚实四态（EMPTY / UNSIGNED / SIGNED / VERIFIED）：`orbit report`
3. **ED25519 签名**——报告由确定性派生的密钥对签名（备份 seed、交出公钥）；`orbit verify-report` 只凭公钥证明报告真实未篡改——**外部审计员可接受的文件，不是内部工具输出**

## 控制台：给客户看证明面，机制收在折叠里

- **重放时间线**：录制窗口展开成可逐步回放的时间线——每一步的输入摘要、输出、耗时、token、治理决策徽标（限流/熔断/越权/预算/压缩/路由）
- **分叉实验**：从任意一步分叉，保留 `0..at` 历史，从该点继续跑新实验——复用内核快照恢复原语，不新增机制
- **对外三样**：审计链卡、合规报告卡、签名卡——给客户/合规看的证明面

## 生态嵌入：编排框架不用改，工具调用交给它

LangGraph / AutoGen / CrewAI / 自研图，都能挂。Orbit 不参与调度，它接管的是每一次**工具调用、模型调用、通道调用**——也就是图里所有"动作"型的边。节点逻辑保持你的，跨节点的副作用被它收口。

```js
// examples/langgraph-orchestration.mjs
const host = bootHost({ governance: "strict" });
```

## 谁该用 · 谁别用：诚实劝退也是产品的一部分

**✓ 该用（use when）**
- Agent 已经进了生产：月度账单 ≥ 1 万、故障 ≥ 月 1 次
- 需要回答"那次调用花了多少、走的哪条路由、是否被熔断"
- 合规团队要求"日志不可篡改、能拿出去举证"
- 在用 LangGraph / AutoGen / CrewAI，想要确定性而不换框架

**✗ 别用（avoid when）**
- 还在原型/演示阶段，跑通就行
- 每次调用都想省那 1ms 重放开销
- 想要的是另一个编排框架
