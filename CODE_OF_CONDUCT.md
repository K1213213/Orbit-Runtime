# Code of Conduct

## Our standard

We aim to make Orbit Agent Runtime a constructive, safe space for everyone who
participates — contributors, reviewers, users and maintainers alike.

In all interactions, we value:

- **Clarity over noise** — review the code, not the person; prefer concrete
  suggestions to vague criticism.
- **Small, reviewable changes** — one purpose per PR, tested before opening.
- **Honesty about trade-offs** — the project deliberately stays zero-dependency
  and small; proposals that grow the surface should justify themselves.
- **Respect for time** — answer questions with the shortest correct response,
  and ask questions only after reading the docs.

## Unacceptable behavior

Harassment, personal attacks, trolling, doxxing, or any conduct that makes
others unwilling to participate. This includes private channels and DMs
related to the project.

## Reporting

Contact the maintainers via a GitHub issue marked `conduct` (or a private
Security Advisory for sensitive cases). Reports are handled confidentially
and proportionately: a warning, removal of content, or a temporary ban
depending on severity and repetition.

## Scope

Applies to all project spaces (issues, PRs, discussions, chat) and to
maintainers equally.
